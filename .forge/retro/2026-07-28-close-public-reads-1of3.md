# 2026-07-28 — 무인증 read 닫기 1/3 (구루·랭킹·수급·공매도 9개 인증 게이팅)

> ADR-0029 3부작의 첫 부. `fg-next all` 드라이브가 회고를 자동 스킵했고 같은 날 사람이 일괄 승급했다.

## 계획 대비 실제

- **계획대로**: S1(무토큰 401 단언 9건 red) → S2(라우터 4파일에 `_: str = Depends(get_current_user)`) → S3(자체-app override) → S4(배포 후 라이브 스모크 9/9 + 프론트 3/3). 백엔드 1342 passed. 감사 대상 4파일이 전수 grep 결과와 정확히 일치(누락 0).
- **괴리 ①(가장 중요) — 계획에 문서 슬라이스가 없었다.** CLAUDE.md는 "인증 게이팅을 바꾸면 `API_SPEC.md` 갱신(DoD)"을 명시하는데 S1~S4에 문서 항목이 없었다. 실제로 `GET /api/rankings`·`GET /api/investor/screening`·`GET /api/stocks/{ticker}/investor-trend` **3곳이 `**Auth:** 불필요`로 적혀 있어 이번 변경으로 즉시 틀린 문서**가 됐고, 나머지 6곳은 Auth 줄이 아예 없었다 → 9곳 모두 `Bearer token 필요`로 갱신. `test_api_doc_sync.py`는 엔드포인트 *존재*만 대조하므로 이 auth 산문 drift는 자동검출 밖이다.
- **괴리 ② — 감사 4파일 중 실변경은 3파일.** `test_batch_endpoints.py`는 이미 두 헬퍼(`_admin_app`/`_user_app`)에서 `get_current_user`를 override하고 호출 대상도 POST `refresh` 계열뿐이라 무영향. 계획이 "이미 있을 수 있다"로 예견한 케이스가 적중.
- **괴리 ③ — red의 실패 양상이 예상과 달랐다(결론 동일).** 계획은 "현재 200이라 실패"를 예상했으나 실제로는 guru 4개가 `RuntimeError: tests must not touch the real DB`(conftest `_block_real_db` 발동), rankings·investor·short-sell 4개가 500, `crawl/progress`만 200. 즉 **무인증 요청이 핸들러를 지나 DB 계층까지 도달**하고 있었다 — 취약점이 예상보다 선명하게 드러났다.
- **괴리 ④ — 워크플로우 없이 직접 실행.** 세션이 워크플로우·서브에이전트 금지였고 작업도 "의존성 1줄 × 9 + 테스트"인 기계적 소규모라 fg-run의 "규모가 작으면 직접 처리가 더 싸다" 지침을 따랐다. §3 조건부 코드리뷰는 직접 정독으로 대체(그 산출물이 아래 프론트 위험 특정).

## 학습

- **프론트 회귀의 진짜 위험 지점은 화면이 아니라 `api.js` 인터셉터다.** `frontend/src/api.js`의 응답 인터셉터는 **401을 받으면 토큰 2개를 지우고 `window.location.href = '/'`로 하드 리다이렉트**한다. 즉 게이팅한 read 중 하나라도 로그인 사용자에게 401이면 **강제 로그아웃**이 된다. → 인증 게이팅 UAT의 판정을 "화면이 예쁘게 뜨는가"가 아니라 **"대상 경로 응답에 401이 0건 + 토큰 잔존 + `/`로 튕기지 않음"**으로 세울 것. 이 판정 골격을 2/3·3/3이 그대로 재사용했다.
- **다음에 다르게 할 것 — 인증 슬라이스에 문서 갱신을 *슬라이스로* 넣는다.** 착수 즉시 `grep -n '\*\*Auth:\*\* 불필요' API_SPEC.md`를 돌려 "곧 틀릴 표기"를 먼저 세어볼 것. (2/3·3/3이 이 관찰을 실행해 각각 4곳·1곳을 더 찾아냈다 — 관찰이 실제로 값을 만들었다.)
- **admin 화면에 매달린 read는 테스트 계정으로 브라우저 검증이 불가하다.** `guru/crawl/progress`는 크롤 화면(admin)에서만 호출돼 `test@portfolion.com`(비admin)으로 못 태웠다. API 스모크로 판정하고 그 한계를 run.md에 남기는 방식이 실용적이었다(CLAUDE.md admin-표면 가토의 read판).
- **브라우저 커버리지를 과장하지 말 것.** 최종 브라우저 커버는 9경로 중 6(`crawl/progress`는 admin, `investor-trend`·`short-sell`은 리포트 상세 진입 실패). 프로브 출력에 "실제로 태운 경로"를 열거하게 만들어 커버리지를 정직하게 드러냈다.
