# 2026-10-06 — 앤트로픽 IPO 글의 9렌즈 분석 프레임을 서클(CRCL)에 시험 적용 (task#367)

## 계획 대비 실제
- 계획대로 된 것:
  - S1 기준선 슬라이스(1차 공시 사실 테이블)를 맨 앞에 둔 덕분에, 계획 시점 가설(지식 컷오프 2026-06 기준)이 실측에 반박된 것이 첫 슬라이스에서 드러났다. USDC는 성장 중이 아니라 1년간 −1%였고, 연준은 9월 17일에 금리를 올렸다. CLAUDE.md의 「계획의 수치·상태 서술은 착수 시점에 이미 틀렸을 수 있다 → baseline 슬라이스를 S0/S1에」 규율의 양성 사례다.
  - 숫자마다 출처·기준일을 붙이는 규율(facts.json, 재무는 sec.gov만)이 끝까지 유지됐다(65 → 83건). 출처 사슬 렌즈를 분석 자신에게도 적용한 결과, 1차 공시끼리 조정 EBITDA 성장률이 8%(보도자료, 새 정의로 전년 재계산)와 14%(10-Q 표, 새 정의 vs 옛 정의)로 갈리는 것을 찾았다.
  - DoD 마커(`data-fit`)를 분류 표식으로 두고 화면 문구와 분리해 둔 덕분에, 「변형 필요 → 변형 완료」 라벨 정정이 DoD를 깨지 않았다.
- 계획과 갈린 것 (전부 실행 후 사용자 대화에서 정정됨 — 정정 4회, Version 1 → 5):
  1. **렌즈 판정 기준을 회사의 상태로 세웠다.** 렌즈 5(현금 런웨이)를 「흑자·무차입이라 부적합」으로 판정했다. 사용자가 「흑자/적자 기준이 아니라 스테이블코인 회사의 특징 아닌가」라고 지적했고 그게 맞았다. 서클의 흑자 자체가 금리 수익 구조의 결과라, 금리가 1.7~2.15% 아래로 내려가면 적자로 뒤집힌다. 기준을 구조 세 축(A 수익 엔진 · B 비용 성격 · C 자금 원천)으로 다시 세웠고, 「앤트로픽을 넣으면 세 축 모두 원글 렌즈가 나와야 한다」로 기준을 검증했다.
  2. **모델 가정을 회사 공시와 대조하지 않았다.** 금리 변화분 중 서클 몫을 평균값 38.2%로 썼는데, 10-Q Item 7A의 회사 금리 민감도(±100bp → 준비금 수익 ±7.37억, 분배비용 ±3.60억)는 한계값 51.2%였다. 손익분기 금리(1.7% → 2.15%), 민감도 표 폭(21~75배 → 20~88배), 렌즈 5 신호(초록 → 노랑)가 함께 틀렸다. 계획의 「무작위 재무 숫자 3건 원문 대조」는 숫자 *존재*만 확인했고 *모델 가정*은 대조 대상에 없었다. 이 오류는 구조 축 기준(렌즈 8: 「민감도는 Item 7A와 맞춘다」)을 세운 뒤의 재분석에서야 드러났다.
  3. **배지가 상태가 아니라 분류를 말했다.** 변형을 적용한 뒤에도 「변형 필요」(호박색 경고 톤)가 남아 미완료처럼 읽혔다(사용자가 폰 스크린샷으로 지적).
  4. S3에서 원글의 「조정 영업이익」 대신 조정 EBITDA를 썼다(서클이 공시하지 않음). 이후 주식보상이 조정 EBITDA의 약 37%라 조정 지표가 희석 비용을 감춘다는 점을 렌즈 8에 추가했다.
  5. 사용자 요청으로 종목 신호등(렌즈별 빨강·노랑·초록)을 추가했다. 계획에 없던 산출이다.

## 배운 것
- 다음에 다르게 할 것:
  - **분석 틀을 다른 대상에 옮길 때, 적합도 판정 기준은 대상의 「상태」(흑자·성장률·금리 수준)가 아니라 「구조」(무엇으로 벌고, 어떤 비용이 매출을 따라가고, 누구의 돈으로 굴러가나)로 세운다.** 상태는 구조의 결과라 조건이 바뀌면 판정이 뒤집힌다. 기준을 세웠으면 원래 대상(여기선 앤트로픽)을 넣어 원래 결론이 재현되는지로 검증한다.
  - **외생 변수(금리·원자재 가격)에 묶인 회사의 민감도는 내 모델을 만들기 전에 회사의 시장 위험 공시(10-K/10-Q Item 7A)부터 읽는다.** 평균 비율과 한계 비율이 다를 수 있다(이번엔 38% vs 51%). 사실 대조 단계에는 「숫자가 출처에 있는가」와 별도로 「모델이 쓴 가정이 회사 공시와 맞는가」를 한 줄 넣는다.
  - **숫자의 정의 변경을 출처 사슬의 한 고리로 본다.** 같은 회사·같은 날 낸 두 1차 문서도 non-GAAP 정의가 바뀌면 성장률이 갈린다. 비교하기 전에 그 지표에 「(New Definition)」·재계산 표기가 있는지 본다.
  - **상태 배지는 「무엇인가」(분류)가 아니라 「지금 어떤가」(상태)를 말해야 한다.** 작업 뒤에도 남는 라벨에 「필요」 같은 미완료 어휘를 쓰지 않는다. 분류 표식(마커·검사 대상)과 화면 문구를 분리해 두면 문구만 안전하게 바꿀 수 있다.
  - 이번 결과는 이 프레임을 앱에 넣는 후속 태스크의 입력이다: 종목마다 구조 세 값(A·B·C)을 붙이면 렌즈 9개의 질문이 정해진다. PortfoliOn에는 CRCL 스냅샷·컨센서스가 없어 앱 데이터를 하나도 쓰지 못했다.
