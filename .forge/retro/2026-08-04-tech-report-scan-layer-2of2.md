## 학습

### 1. ellipsis + 한국어 어순 — 잘리는 것은 늘 "무슨 일이 일어났는가"다 (⭐ 승급)
타임라인 이벤트 라벨이 116px에서 잘렸는데, **한국어는 동사가 문장 끝에 온다.** `로모노소프 부유식 원전
상업운전` → `로모노소프 부유식 …`로 **주어만 남고 사건이 사라진다.** 하필 루틴 프롬프트가 요구하는 정보
(가동·착공·계통연결·상업운전)가 정확히 그 자리다. 기존 가토 ⑦은 「중요한 *수치*를 끝에 두지 말 것」이었는데
한국어 **문장**에는 훨씬 세게 적용된다.
복구 경로 둘 다 막혀 있었다 — `<title>` 툴팁은 터치에 hover가 없고 `role="img"`가 AT에서 자손을 감춘다.
그리고 `minWidth == maxWidth`라 **PC 1440에서도 동일하게 잘렸다**(「좁은 화면 문제」라는 직관이 틀린 경우).
해법: 그 SVG는 이미 **무한폭 가로 스크롤러 안**이라 자를 구조적 이유가 없었는데도 `COL_W`가 상수였다
(헤더 주석이 스스로 "축소 대신 스크롤"을 못박아 놓고 폭만 고정한 모순). 라벨 실측 최대폭 파생 + 측정기 주입.

### 2. `role="img"`가 접근성 트리에서만 정보를 지운다 (⭐ 승급 — 여섯 번째 클래스)
화면은 완벽한데 보조기술에는 아무것도 없는 경우다. 기하·색·잘림 축 어느 것도 원리적으로 못 본다.
타임라인 5건이 "진척 타임라인, 이미지" 한 마디가 됐고, **하필 이 섹션은 산문에 묻힌 정보를 끌어올리려고
만든 것**이라 같은 내용이 화면 어디에도 텍스트로 중복되지 않아 **스크린리더 사용자에게 추가된 정보가 0**이었다.
같은 가족: `<details>` 대신 JS 상태로 접으면 닫힌 본문이 DOM에서 사라져 Ctrl+F·스크린리더가 못 찾는다
(`PlayerTable` note가 그랬고 네이티브 `<details>`로 고쳤다).

### 3. 미러링은 결함도 함께 복제한다 — 고칠 땐 두 표면을 같은 커밋에서
핵심 포인트 카드가 `AnalystReport`의 포인트 블록을 미러링했는데 이중 음수(`▼-12.5%`)까지 따라왔다.
구현자가 "임의로 고치면 심층 리포트와 표기가 갈라진다"며 일부러 둔 판단은 **합리적이었다** — 그래서 수정은
한쪽이 아니라 **두 표면을 같은 커밋에서** 맞췄다. 미러 관계를 만들 때는 "원본의 결함을 발견하면 어떻게 할
것인가"를 미리 정해 두는 편이 낫다.

### 4. 센티넬 문자열은 데이터와 충돌한다
`CategoryGroups`의 `UNCLASSIFIED = '미분류'`가 Map 키 겸 표시 라벨이었다. `category`는 자유 문자열이고
루틴 프롬프트도 "통용 분류를 쓰라"만 지시하므로 루틴이 실제로 `"미분류"`를 쓸 수 있고, 그러면 분류 못 붙인
버킷과 **조용히 합쳐진다.** → `Symbol` 키 / 표시 라벨 분리. (기존 가토 「필드를 합치는 리팩터에선 역할 수를
세라」의 사촌 — 여기선 *한 상수*가 키와 라벨 두 역할을 겸했다.)

### 5. `json.dumps(None)`은 SQL NULL이 아니다
JSONB 컬럼에 캐스트되면 **JSON null 스칼라**가 되어 `IS NULL`이 False다. 같은 컬럼에 두 종류의 NULL 표현이
공존한다. 리뷰어가 컨테이너에서 **읽기전용으로 실측**해(쓰기 0, rollback) 확정했다.

### 6. 세션 한도 실패는 무손실이었고, 확인 절차가 그것을 확정했다
수정 워크플로우 2 에이전트가 모두 `session limit`으로 죽었다(`agents_done: 0`). 실패 통보만 보고 "부분
적용됐을 수 있다"고 넘겨짚지 않고 `git status`·양 스위트로 작업트리가 온전함을 먼저 실측한 뒤 재실행했다.
부수 확인: **`HEAD == origin/main`이면 2분 폴러가 skip하므로 미커밋 작업트리는 안전**하다
(폴러는 `LOCAL != origin/main`일 때만 `reset --hard`한다).

### 7. 응답 계약이 `null`이라 렌더 가드가 필요했다
정규화(None→[])를 하지 않아 배열 자리에 `null`이 온다. 게다가 구발행물의 `players[]`엔 `category` **키 자체가
없다**(JSONB에 박제된 옛 형태 → `undefined`). `??`가 둘을 함께 흡수한다. `change_pct`는 `0`도 유효값이라
`if (change_pct)`가 아니라 `!= null`로 분기해야 한다.
