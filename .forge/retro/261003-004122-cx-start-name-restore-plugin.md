## 배운 점
- 다음엔 다르게:
  - **Claude Code `settings.json`의 `env`는 셸 환경변수를 덮어쓴다.** 플러그인 로드 확인은 `CLAUDE_CODE_PLUGIN_DIRS`가 아니라 `--plugin-dir` 플래그로 할 것(환경변수로 줬더니 프로브가 로드돼 영구 플러그인은 0건으로 보였다).
  - **빈 세션은 jsonl이 없다.** ← 뒤 이름 역추적은 원 세션의 `~/.claude/sessions/<pid>.json`(`name`·`nameSource:user`·`parkedJobId`=bg 세션 ID 앞 8자)로 한다. #364의 `continuedInSessionId` 방식은 대화가 있는 세션에서만 성립한다.
  - 플러그인 함정 2건: `$.process.run`은 `{argv}` 객체가 아니라 **배열**을 받는다. 쉘 스크립트를 `String.raw` 템플릿에 넣을 때 `${`가 있으면 JS 식으로 평가돼 모듈이 로그 없이 깨진다.
  - 약한 증거: DoD 7(일반 세션 지연)은 탑재 전 수치 없이 절대값(5.9s)만 봤다. 변화량을 주장하려면 전후를 함께 재야 한다.
- 후속 후보:
  - `/clear` 뒤 ←에서도 같은 방식으로 이름이 복원되는지 측정해 `cc-clear-prime`(1턴)을 통합 폐기할 수 있는지 판단한다(미측정).
