# 2026-08-11 — 첫 페인트 전에 테마를 확정한다 (task#286)

fg-loop 무인 드라이브가 자동 스킵한 회고의 **유예 승급**(batch promotion, 2026-08-11 일괄). 커밋 `5b18504`·`1aeaca2`.

## 계획 vs 실제

**계획대로 된 것**

- **인라인 배경 CSS가 핵심이라는 계획의 판단이 정확했다** — red-first 대조군에서 부트스트랩의 `localStorage` read만 무효화하자 다크 사용자의 첫 페인트가 `rgb(246,241,231)`로 재현됐다(축이 결함을 실제로 관측할 수 있음을 증명).
- **S5(빌드)를 S6(라이브 UAT)보다 먼저 배치**한 순서가 옳았다. nginx가 `frontend/dist`를 직접 서빙하므로 빌드 전에는 S6 완료기준이 원리적으로 달성 불가였다.
- **빌드를 메인 세션 단독 구간으로 뺀 것**이 유효 — 라이브를 재는 에이전트가 도는 동안 배포성 행위 0건, 측정 오염 0건.
- 서브에이전트 금지 항목 위반 0건(8 에이전트 전원). red-first 실증은 전부 파일 내 편집→원복.
- 회귀 게이트 5프로브 각 2회 전부 PASS, 총계 일치, 스테일 축 0건.

**일탈**

1. **회귀 게이트가 이번 변경의 절반에 원리적으로 블라인드함이 드러났다** — 5프로브 전부 신규 컨텍스트 + `localStorage.theme` 미설정 + Playwright 기본 `colorScheme:'light'`라 `[data-theme="dark"]` 규칙이 한 번도 매치되지 않는다. `uat285/C4`는 두 스플래시의 computed 값을 **서로** 비교하는 상대 단언이라 양쪽이 동시에 라이트면 통과한다 → **그 게이트의 PASS는 "다크 사용자 스플래시가 옳다"를 증언하지 않는다.** 프로브 에이전트가 스스로 발견해 스플래시 축 10건을 추가했다.
2. **S3가 프로덕션 코드 변경 0으로 끝났다** — 인계 지점에서 값이 뒤집힐 위험을 경계했으나 `useTheme`의 `applyTheme('dark')`가 인라인과 같은 값을 쓰는 no-op이었다. 계획이 틀린 게 아니라 **위험이 실재하는지 확인한 결과 없었던** 것이다(테스트는 계약을 못박는 용도로 잔존).
3. **적대적 리뷰의 유일한 미확증 발견이 서브에이전트가 원리적으로 볼 수 없는 자리였다** — 렌즈1이 「Vite 프로덕션 빌드 후 실제 `<head>` 순서 미확인」을 `verified:false`로 올리며 사유를 **"도구 범위 밖 — 빌드가 금지돼 있고 빌드 자체가 배포 행위"**라고 정확히 적었다. task#285 가토(`confirmed`로 필터링하지 말 것)대로 심각도로만 필터했고, 배포 직후 메인 세션이 `dist/index.html`을 직접 파싱해 5개 순서 조건을 확인했다. **가토가 지시로 이월돼 작동한 양성 사례.**
4. **W1(순수 인라인 창)은 캡처가 원리적으로 불가능** — 미도착 render-blocking 스타일시트가 있으면 first paint 자체가 없어 CDP `captureScreenshot`이 6/6 타임아웃한다. 프로브가 이를 라벨링하고 판정은 computed style로, 시각 확인은 빈 CSS fulfill arm이 대신하게 분리했다(⑧ⓖ 준수). 부수: 그 창엔 `document.body`조차 없다(`<head>` 끝 parser-blocking `<script src="/registerSW.js">`가 앞선 미완료 스타일시트를 기다려 파서가 head에서 멈춘다).
5. **프로브 자신의 결함 3건이 최초 실행에서 red로 드러났고 앱 결함은 0건이었다** — `document.body`를 W1 대기 조건에 넣어 무음 타임아웃 · 스플래시 arm에서 번들 CSS 게이트 · 정의역 sentinel이 크로스오리진 폰트 시트의 `cssRules`를 읽다 `SecurityError`. 판정 전에 "앱 결함인가 계측 결함인가"를 실측으로 가른 것이 값을 했다(⑧ⓓ).
6. **파일 크기 우연이 육안 검증을 흔들 뻔했다** — `pc-dark`와 `pc-light`가 똑같이 5855바이트로 나왔으나 md5는 달랐다. 단색 PNG는 색이 달라도 압축 구조가 같아 크기가 일치할 수 있다.
7. 리뷰 렌즈3이 `npm run dev`를 임시 포트로 잠깐 띄웠다(즉시 종료). 금지 목록이 `npm run build`/`vite build`만 대상이라 저촉은 아니지만, **금지 항목을 "빌드"가 아니라 "라이브 산출물을 바꾸는 행위"로 표현했으면 더 정확했다.**
