## 학습
- **리서치 하위탭은 두 곳에 이원화돼 있다 — 모바일 `ResearchShell.RESEARCH_TABS` / PC `Masthead.SECTIONS[research].items`.** ResearchShell만 고치면 PC에서 새 탭에 진입할 수 없다(이번에 실제로 그랬고 라이브 UAT가 잡았다). **탭 추가·개명·삭제는 항상 두 목록을 쌍으로** 손댈 것.
- **낙관 갱신 UI를 테스트할 땐 클릭 순서가 상태를 지운다** — "해제 → 발행" 순으로 클릭하면 해제로 행이 사라져 발행 버튼이 없어진다. 낙관 갱신 화면의 테스트는 순서 독립적으로(또는 각 케이스를 별도 render로) 짜야 한다.
- admin 화면의 시각 확인은 여전히 사용자 경유(테스트 계정 비admin) — 기능 경로는 vitest+API로 닫고 렌더는 사용자에게 넘겼다.
