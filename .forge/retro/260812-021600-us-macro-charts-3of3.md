# 2026-08-12 — 시장지표에 미국 절사평균 물가(4종 YoY) 섹션 추가 (task#295)

fg-loop 드라이브 3/3(마지막). 워크플로우 6페이즈·9 에이전트·오류 0. eco. 배포·라이브 UAT 통과(verified: yes).
형제 2건의 교훈 **6가지**를 지시로 박고 실행 — **적대적 검토 확증 결함 0건**으로 끝난 유일한 파트다.

## Plan vs actual

- What went as planned:
  - **6가지 교훈이 전부 값을 했다** — `run.set_status` 재발 0 · 정확수 8곳 누락 0 · `leaf-lines` 거짓 FAIL 0 · 병렬 wave 오염 0 · `API_SPEC`의 `partial` 예시가 **처음부터 `ok: false`**(294가 겪은 복제 오기 재발 0) · 뷰포트 4종 사전 지정.
  - **단위 혼동(이 파트의 최대 위험)이 설계로 차단**됐다. 4종 중 2종은 FRED가 이미 %(≈2.2)로, 2종은 지수(≈131)로 발행한다. 저장은 원계열 그대로 두고 `_series_view`가 `kind`로 분기해 index만 `yoy_from_index`로 파생, percent는 패스스루 — **YoY 이중 적용이 원천 차단**되고 프론트는 단위 분기를 갖지 않는다.
  - **실측 회귀 케이스가 이빨을 가졌다** — 지수 fixture(전년 125.00 → 129.1125 / 129.5875)로 코어 PCE 3.29 · 헤드라인 3.67을 재현. 검토 렌즈가 `129.1125/125.00 − 1 = 0.0329`를 **수동 재계산해 검산**까지 했다.
  - 라이브 4종 최신값이 계획 실측과 **정확히 일치**(3.29 / 3.67 / 2.23 / 2.63), 히스토리 |max| 5.01~7.24로 **지수 미혼입**. 헤드라인 7.24가 2022 인플레 정점이라는 것도 역사적으로 옳다.
  - S2가 **`partial` 응답 바디 단언을 신설** — 294 회고가 남긴 후속을 이 파트에서 해소해, 문서-코드 `ok` 불일치가 스위트에 처음으로 걸리게 됐다.

- Divergences:
  1. `job_runs.py` docstring이 3번째 쌍(절사평균 물가 2경로)을 누락(LOW). **294에서도 같은 형태**가 났다 — 수동 나열을 유지하는 한 새 배선마다 재발한다.
  2. jsdom이 recharts `<Legend>`를 렌더하지 않아 **범례를 차트 바깥 plain DOM으로** 만들었다. 계획은 "범례에 최신값"만 요구했고 수단은 열려 있었으므로 이탈이 아니며, 결과적으로 **테스트 가능성과 접근성(텍스트가 DOM에 실재)이 함께 좋아졌다**.
  3. 지수 파생 계열이 % 계열보다 12개월 짧다(라이브 `n=102` vs `n=114`) — YoY 파생이 첫 12개월을 소비하므로 **정상**이고, 계획이 조회 시작을 `year-9`로 잡은 이유다.
  4. FRED 최신이 2026-06인데 원본 이미지는 「7월까지」(블룸버그 추정 포함) — **결함 아님**. 계획이 미리 적어 뒀고 라이브에서 4종 모두 `latest_date = 2026-06-01`로 확인됐다.

## Learnings

- Do differently next time:
  - ⭐ **단위가 섞인 외부 계열은 "어디서 통일하느냐"를 먼저 정하라.** 저장을 원계열로 두고 **응답 시점에** 통일하면 ⓐ `_merge_history` 증분이 유지되고 ⓑ 프론트에 단위 분기가 생기지 않아 **혼동이 한 곳으로 모인다**. 반대로 프론트에서 통일하면 소비처마다 분기가 복제된다. 이 파트의 최대 위험이 설계 한 줄로 사라진 이유다.
  - **단위 위험은 판정축을 "범위"로 두면 값싸게 잡힌다** — 「모든 값이 0~10%」 한 줄이 지수(131) 혼입을 전 계열·전 히스토리에서 즉시 잡는다. 절대 정확성을 재는 것보다 훨씬 싸고, 실제로 이 파트의 킬러 축이었다.
  - **YoY·전년비류는 날짜 키로 계산하고 결손 케이스를 테스트로 못박아라**(294와 동일 교훈의 2번째 관측). 인덱스 오프셋은 결손 시 *조용히* 다른 달과 비교하므로 값이 그럴듯해서 리뷰로도 안 잡힌다.
  - **수동 나열 목록은 드리프트한다** — `job_runs.py` docstring이 2연속 뒤처졌다. 나열 대신 **조건 서술**("실패를 삼키고 dict를 반환하는 fetch를 감싸는 잡은 모두")로 바꾸면 새 배선이 늘어도 문서가 옳게 유지된다.
  - **jsdom 제약을 우회한 선택이 더 나은 구현이 되기도 한다** — 범례를 plain DOM으로 옮긴 것은 테스트 가능성 때문이었지만 접근성·Ctrl+F까지 같이 좋아졌다. "테스트가 못 본다"를 만나면 우회 전에 **관측 가능한 형태로 바꿀 수 있는지** 먼저 보라.
