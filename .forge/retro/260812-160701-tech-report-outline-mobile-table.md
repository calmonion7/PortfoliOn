## 배운 것

### 다음에 다르게 할 것
- **스크롤러·`minWidth`를 제거하는 변경은 전 텍스트 셀을 `anywhere`로.** `break-word`는 "문자를 잃지 않는다"만 만족시키고 최소폭은 줄이지 못한다 — 두 축을 구분해서 쓸 것.
- **프로브 slug는 「문자열 최장값」으로도 고른다.** 계획의 "전 열 판" 지목이 두 번 틀렸고(계획 → 메인 정정 → 적대 검토 재정정), 최악값 판을 넣은 것만으로 배포 회귀가 잡혔다.
- **바뀐 *동작*을 단언하는 축은 처음부터 전 프로브 grep.** 한 곳을 고친 것으로 끝이 아니다(3회 밟았다). `grep '<속성|심볼>' scripts/*.mjs`를 첫 수정 *전에* 돌릴 것.
- **두 기록된 결정이 충돌하면 셋째 선택지를 먼저 찾는다.** 목차 위치를 옮겨 둘 다 만족시켰다 — tension wall의 "satisfy BOTH" 처방을 사람 개입 없이 in-scope로 해결한 형태이고, fork를 선언하기 전에 이걸 시도할 것.
- **속성·필드를 새 소비처가 재사용하려 할 때 「그러면 이 이름의 개수가 무엇과 어긋나는가」를 물을 것.** 어긋나면 소비처마다 리터럴 필터가 생기고, 그 리터럴은 곧 3곳에 복제된다(task#251의 DOM 속성판).
- **육안 확인을 완료기준에 넣은 것이 값을 했다** — 프로브 468단언 ALL PASS 뒤에도 m350 표·PC 목차의 실제 가독성은 스크린샷 2장으로만 확인된다.
